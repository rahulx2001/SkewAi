## How to run

```bash
# API must be hardened and reachable
export FRONTLINE_API_KEY=… SESSION_SECRET=… FRONTLINE_AUTH_REQUIRED=1 PILOT_HARDENED=1
uvicorn src.api.main:app --host 127.0.0.1 --port 8000

cd dashboard
export E2E_API_KEY="$FRONTLINE_API_KEY"
npm run test:e2e
```
